## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
npm install
cd client && npm install
```

### Step 2: Start Servers
```bash
# Terminal 1
npm run server

# Terminal 2
cd client
npm start
```

### Step 3: Open Browser
```
http://localhost:3000
```

**That's it! You're ready to go! 🎉**

## 🎓 Sample Test Flow (5 Minutes)

### 1. Register Account
```
Name: Test User
Email: test@example.com
Password: test123456
```

### 2. Generate Timetable

**Step 1: Basic Info**
```
College: CS Department
Course: B.Tech CS
Semester: 5
```

**Step 2: Schedule**
```
Days: Monday-Friday
Time: 09:00 - 17:00
Duration: 60 minutes
Lunch: 13:00 - 14:00
```

**Step 3: Subjects**
```
1. Data Structures - 4 hrs/week
2. Operating Systems - 4 hrs/week
3. DBMS - 3 hrs/week
```

**Step 4: Faculty**
```
Skip or add 1 teacher
```

**Step 5: Rules**
```
Max: 6, Min: 4
```

**Step 6: Review & Generate!**

- Click "Save Timetable"
- Go to "History" page
- See your saved timetable!
